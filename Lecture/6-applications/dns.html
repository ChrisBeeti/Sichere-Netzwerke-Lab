Konzept
DNS ist ein hierarchisches, verteiltes Dateisystem. Jede Ebene kennt nur ihre eigenen Einträge — und welcher Server für die nächste Ebene zuständig ist.
Auflösung
www.example.de wird von rechts nach links aufgelöst:
. → de → example → www
Port
UDP 53 für normale Abfragen · TCP 53 für Zonentransfers und Antworten > 512 Byte
FQDN
Fully Qualified Domain Name: www.example.de. — abschließender Punkt bezeichnet die Root-Zone

Vorteil
Client stellt eine einzige Anfrage und erhält die fertige IP-Adresse. Kein weiterer Aufwand für den Client.
Nachteil
Resolver trägt die gesamte Last. Bei vielen Clients kann er zum Engpass werden.
Typisch
Browser → ISP-Resolver (z. B. 8.8.8.8) → Root → TLD → Auth. Häufigster Einsatz im Internet.
Cache-Nutzung
Der Resolver cached alle Antworten mit TTL. Nächste Abfrage derselben Domain: sofortige Antwort ohne Root-Abfrage.
Iterative (nicht-rekursive) Abfrage — Client fragt jeden Server selbst

Vorteil
Client hat volle Kontrolle über den Prozess. Resolver-Server werden entlastet.
Nachteil
Client muss jeden Server selbst befragen. Mehr Anfragen, mehr Netzwerklast beim Client.
Typisch
Zwischen DNS-Servern untereinander (Root→TLD→Auth). Browser selbst nutzt meist rekursiv.
Antwort
Jeder Server antwortet nur mit dem nächsten Schritt in der Hierarchie — kein Weiterfragen im Auftrag des Clients.

Caching & TTL
Jeder Resource Record hat ein TTL-Feld (Time to Live, 4 Byte). Nach Ablauf der TTL-Sekunden löscht der Resolver den Eintrag aus seinem Cache und fragt erneut nach.

Kurze TTL: schnelle Propagierung von IP-Änderungen, aber mehr Last.
Lange TTL: weniger Anfragen, aber Änderungen dauern länger.
DNS-Sicherheit
DNS Spoofing / Cache Poisoning: Angreifer injiziert gefälschte Einträge in den Cache.

DNS Amplification Attack: DDoS-Verstärker — kleine Anfrage, große Antwort.

DNSSEC: Digitale Signaturen für Resource Records.
DoH / DoT: DNS über HTTPS/TLS — Verschlüsselung gegen Mitlesen.
Zonen-Management
Primary Name-Server: Bezieht Informationen aus dem Master File (DNS-Datenbank).

Secondary Name-Server: Kopiert Zonendaten regelmäßig via Zone Transfer vom Primary (TCP 53).
